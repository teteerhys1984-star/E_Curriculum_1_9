## Standard applied

- Each writing activity is a separate `data-writing-activity` group on its source page with response entry, local draft persistence, an activity-specific reset and, where the source supports one, a labelled model. Revealing a model never overwrites the pupil’s draft.
- Map and picture answers are labelled **inferred/source-derived**, never printed answer keys. The PB p.28 passage-derived tick/cross and choice answers are likewise labelled inference.
- The PB p.27 duplicated printed number `4` for Bakery and School is preserved verbatim, disclosed on the page and never used as an unambiguous key.
- Open and personal prompts show labelled illustrative examples where answers vary; no unique answer or automatic score is claimed. Drawing is not checked.
- WB exercise 6 has no model: no recording or transcript was supplied, so the four empty boxes remain explicitly unavailable for audio verification.
- Nothing in the textbook exercises is autograded. The independent Lesson Test is a separate assessment with its own 12 authored items and teacher key.
