## Transcription notes and honest limits

- The picture column in Pupil’s Book Activity 4 does not line up with the three place sentences (classroom, basketball court, library). It is reproduced in printed order with the mismatch disclosed; only the circled words are scored, because the printed sentences themselves settle them.
- Workbook Exercise 6 prints a sound-pair column and a dotted-word column whose letters do not agree row by row. Both are reproduced as printed, the example line is marked as the book’s, and the inferred word-level answers are labelled as inferred.
- Pupil’s Book labels beside the school picture were partly small; each one is shown as its own 4× crop so the printed position can be checked directly.
