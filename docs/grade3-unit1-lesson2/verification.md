- مراجعة المصدر بندًا ببند: [source-checklist.md](source-checklist.md).
- نتائج الفحص الساكن المنفذ: [static-report.json](evidence/static-report.json) — تشغيل 29 أكتوبر/تشرين الأول 2026، الساعة 22:12:29 UTC؛ **8 فحوص ناجحة**.
- نتائج المتصفح المنفذ: [browser-report.json](evidence/browser-report.json) — تشغيل 29 أكتوبر/تشرين الأول 2026، الساعة 22:14:12 UTC؛ **12 فحصًا ناجحًا** في Chromium 153.0.8010.0.
- الفحص البصري هنا مراجعة لقطات من **Chromium فعلي يعمل آليًا دون واجهة رسومية**، بمقاس شاشة حاسوب محمول 1366×900 ومقاسات أصغر. **ليس اختبارًا على جهاز لابتوب فعلي، ولا على Safari أو Firefox.**
- لم تُختبر التسجيلات الأصلية لأنها غير مرفقة. لم يُنشأ صوت أو نص استماع أو مفتاح استماع بديل.
- روابط المعاينة المحلية ليست روابط نشر GitHub Pages. اختُبر مسار المشروع `/E_Curriculum_1_9/` محليًا؛ النشر العام النهائي يحتاج مراجعة الطلب ونجاح النشر بعد الدمج، ولم يُدمج الطلب ضمن هذه المهمة.

## ما نُفذ فعلًا

### 1. سلامة الملفات والمصدر والروابط

الأمر `npm test` يفحص جميع ملفات HTML في جذر المشروع، وليس الدرس الجديد فقط:

- **35 صفحة HTML و183 مرجعًا محليًا** إلى صفحات وأصول؛ التحقق من وجود الملفات، وعدم الخروج من المشروع، وصحة معرفات الروابط الداخلية.
- عدم تكراد معرفات HTML، ووجود نص بديل لكل صورة.
- بنية الصفحات وفق `LESSON_PAGE_STANDARD.md`: تحميل المتصفح المشترك للتنقل في صفحات المحتوى الأربع، واستثناء صفحة القائمة منه.
- إدراج الدرس الثاني في قائمة الصف الثالث مع الإبقاء على الدرس الأول وقوائم الصفوف الأخرى.
- مقارنة بصمات **الصور الأصلية الست** بـSHA-256، ووجود **27 قصاصة** مشتقة منها.
- خمسة أنشطة لكتاب التلميذ، ستة حوارات، عشرة أعداد؛ ستة تمارين لدفتر التدريبات، ثمانية اختيارات استماع، أربعة فراغات أعداد وأربعة فراغات جدول.
- العشرون سؤالًا و60 خيارًا، ومطابقة نصوص الأسئلة والخيارات والمراجع وترتيب الإجابات مع [ملف المراجعة](../../tests/grade3-unit1-lesson2.quiz.json).
- 15 سؤالًا للقراءة المباشرة و5 للاستنتاج الموسوم؛ مفتاح المعلم مخفي ابتداءً.
- روابط وثائق المراجعة والأدلة، ووجود كل خط مشار إليه في CSS.
- فحص صياغة JavaScript المحلي والمشترك باستخدام `node --check`.

### 2. المتصفح والتفاعل

الأمر `npm run test:browser` يشغّل خادم اختبار تحت مسار المشروع ويستخدم Playwright مع Chromium. التقرير المرفق يسجل التاريخ وإصدار المتصفح وحالات النجاح الفعلية.

- فتح قائمة الصف الثالث والنقر على الدرس الثاني، وفتح الأقسام الأربعة.
- التنقل إلى جميع خطوات الكتابين والمفردات، والتحقق من السابق/التالي والفهرس، ومن فك ترميز الصور المعروضة.
- المرور على **جميع انتقالات الأسئلة العشرين** بزر التالي، في المقاسات الأربعة.
- فتح صور الصفحات الأصلية والتحقق من اتجاه العربية والنصوص الإنجليزية.
- مقارنة نصوص الحوارات والجمل والاختيارات والجداول والفراغات مع التفريغ المرجعي، والتحقق من ترتيب الحوارات يسارًا ثم يمينًا.
- عدم وجود صور كتاب التلميذ داخل صفحة دفتر التدريبات.
- إدخال إجابات دفتر التدريبات، والتنقل بين الخطوات، والتحقق من بقاء الإدخالات، وإظهار/إخفاء الإجابات ومسحها.
- الاستماع قابل للاختيار والمسح، لكن **لا يصحح** ولا يملك مفتاحًا. الكتابة الشخصية لا تصحح آليًا.
- الاختبار دون إجابة: **0/20** مع بيان 20 سؤالًا غير مُجاب؛ كل الإجابات الخاطئة: **0/20**؛ الصحيحة: **20/20**؛ خطأ واحد: **19/20**؛ إجابة صحيحة واحدة والباقي فارغ: **1/20**.
- تغيير إجابة بعد التصحيح يزيل النتيجة القديمة حتى إعادة التصحيح؛ إعادة الاختبار تمسح التحديد والنتيجة والتغذية الراجعة.
- رفض كلمة المرور الفارغة والخاطئة، وقبول كلمة مرور المعلم الموجودة بالمشروع، ووجود 20 دليلًا في المفتاح، والإخفاء وإعادة الإغلاق عند إعادة الاختبار.
- اختيار إجابة بلوحة المفاتيح، واتجاه الخيارات الإنجليزية LTR والتغذية الراجعة العربية RTL.
- المقاسات **1366×900، 768×1024، 390×844، 320×740**؛ عدم وجود تجاوز أفقي على مستوى الصفحة. الجداول العريضة لها تمرير داخلي، واختُبر الوصول إلى طرفيها على الهاتف.
- الرجوع بالنقر من الصفحات الفرعية إلى قائمة الدرس وقائمة الصف الثالث تحت مسار المشروع.
- عدم تسجيل أخطاء JavaScript للصفحات أو استجابات HTTP برمز 400 أو أكثر خلال المسارات المختبرة.

**تنبيه:** عدم وجود أخطاء HTTP في هذه المسارات لا يعني اختبار كل تفاعل ممكن في بقية صفحات الموقع. فحص بقية الصفوف اقتصر على سلامة الروابط وفتح القوائم والتأكد من بقاء روابط الدروس المعروفة.

## إعادة الفحص محليًا وفي الطلب

المتطلبات: Node.js 22.17 أو أحدث، وPython 3 لخادم المعاينة الاختياري. حزم الاختبار مثبتة بإصدارات مقفلة، ولا تحتاج الصفحة المنشورة إلى Node أو إلى اتصال بخدمات خطوط خارجية.

```sh
npm ci --ignore-scripts
npm test
npm run test:browser
```

ينتج فحص المتصفح تقريره و14 لقطة في `test-results/grade3-unit1-lesson2/`، وهو مسار مستبعد من Git. النسخ المختارة أعلاه محفوظة عمدًا ضمن الوثائق. يمكن تشغيل خادم محلي اختياري عبر `npm run serve` ثم فتح `/lessons.html?grade=3`.

أُضيف مسار GitHub Actions باسم **Lesson checks** لتشغيل الفحصين في الطلبات التي تمس ملفات الموقع أو الاختبارات، مع رفع أدلة المتصفح. حالة تشغيله على GitHub تُقرأ من تبويب Checks في الطلب؛ لا يفترض هذا التقرير نجاح تشغيل لم يبدأ بعد. لم تُعدل آلية نشر `main` الحالية، ولم يُنفذ نشر أو دمج من فرع المهمة.

## نقاط تحتاج مراجعة بشرية أو لم تُختبر

1. توفير التسجيلات الأصلية للأنشطة الصوتية ومراجعة مطابقتها؛ لا توجد إجابات استماع معتمدة حاليًا.
2. اعتماد المعاني العربية والصياغات التعليمية المساعدة من المعلم؛ ليست نصًا رسميًا من الكتاب.
3. الفرق بين جواب الأربعاء المنطوق وجدول Wednesday موثق، ولم يخترع تفسير لتوحيدهما.
4. اختبار لمس فعلي وقارئ شاشة وتكبير النص على أجهزة المدرسة؛ الفحص الآلي لا يحل محل اختبار الاستخدام الكامل.
5. Safari وFirefox والطباعة الفعلية وأجهزة فعلية لم تُختبر. توجد أنماط طباعة، لكن لا ادعاء بمراجعة مطبوعة.
6. بوابة المعلم محلية على طريقة المشروع، وليست مصادقة آمنة؛ يستطيع من يقرأ شيفرة الموقع استخراج كلمة المرور والإجابات.
