## Writing standard applied

- Exercises 4, 5 and 7 are managed by `lesson7-writing-practice.js`: drafts are saved in the browser, a labelled model can be shown, comparison never overwrites the pupil's text, and reset affects only that exercise.
- Exercise 2 is not scored and has no model, because the answers come from the clock pictures, which the page does not check.
- Exercise 3 is a choice exercise, so it is managed as a selection with an inferred model. It is not counted as a writing activity.
- Nothing is marked automatically and no score is shown for any Workbook exercise.

## Documented exception

Workbook Exercise 2 (“Look, read and write.”, p. 21) is a writing activity with no printed key. The clock hands in the picture cannot be read reliably from the scan, so no model answer is given. The page discloses that the answers are not scored and that the teacher checks them against the pictures. It is recorded in `docs/english-curriculum-audit/writing-readiness.json`.
