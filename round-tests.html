Round Tests

A comprehensive 40-question test follows every five prepared lessons. Each test reviews the full group, not just one lesson.

How Round Tests work

Round Test 1 covers Lessons 1–5; Round Test 2 covers Lessons 6–10; Round Test 3 covers Lessons 11–15, and so on. Every test contains 40 questions based on the actual material taught in that group.

The test blueprint will include vocabulary, grammar and language use, reading comprehension, and appropriate writing or functional-English tasks, according to the content of the five lessons.
