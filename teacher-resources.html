Read this before using a key

These are source-referenced teaching keys, not the publisher’s official answer key. Where the book prints the answer, the key repeats it. Where the book prints no key, the entry is labelled as an inference and the reasoning is shown. No listening answer has been invented anywhere, because no official recording was ever supplied.

Answer-key areas sit inside six lesson tests and are hidden behind one shared classroom password typed into the page. That password is a display convenience only: the key text is already part of the published page and can be read in the browser without it. It is not authentication, and it must not be used to protect confidential or unpublished material. Real access control requires a server-side check, which this static site does not have.

The in-page reveal counts below are the “show the answers” controls that already exist on some book and Workbook pages. They are visible to pupils too — they need no password. Use them for self-checking or projection, and do not describe them to a class as hidden material.

Unavailable teacher material

  • Official audio recordings and listening answer keys. No recording was supplied for any lesson, so no listening answer exists and those items stay unscored.
  • Cumulative Round Tests. Each round needs five verified lessons; no grade has five yet, so the Round Test page shows status only.
  • Teacher’s guide, lesson plans and schemes of work. Not written for this project and not stored anywhere in it.
  • Marking rubrics and printable worksheets. The existing pages are screen material; no printable pack exists.
  • Class rosters, pupil accounts, marks and progress records. Deliberately absent: the platform has no accounts and no stored pupil data.
  • Grade 4 Lesson 1 answer key. The test page has no key area, and none has been invented for this directory.
  • Verified content for Grades 1, 2, 6, 7 and 9. Only the template preview exists.
