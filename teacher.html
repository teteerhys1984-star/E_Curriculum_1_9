Scope of this portal No sign-in

No accounts, no student records

Opening this portal creates no account and asks for no personal details. Nothing here records marks, attendance, completion or pupil progress, and there is no dashboard to maintain.

The only browser storage in the whole platform is the single “Continue learning” page link kept on this device by the student pages. The teacher pages never write to it, so opening them cannot disturb a pupil’s saved place.

How the answer-key areas work — and what they cannot do

Read this before showing a key in class. The honest description matters more than the convenience.

Display aid only

One shared classroom password hides the key; it does not protect it

Not secure authentication. The answer-key areas on six lesson tests ask for a single classroom password typed into the page. It is not authentication: that password only hides the key from casual view, and the key text is already part of the published page, so anyone can read it in the browser without typing anything. Do not treat the password as a security control, and never place confidential information, unpublished material, marks or personal data behind it.

Genuine access control needs a server to check each request before the answers are sent. This site is a static publication with no server-side component, so that check does not exist here. Adding one is a later architectural step and is not part of this phase; until then the honest position is that the keys are public teaching material with a courtesy screen in front of them.

For the same reason, the practice answer reveals on the book and Workbook pages are open to everyone, including pupils. They are useful for self-checking and for projection, but they are not hidden material.

The classroom password is deliberately not printed anywhere on this portal. If you need it for your class, contact Eng. Somer Shaheen on WhatsApp.

Running a prepared lesson

The four sections keep their own page order, so a lesson can be taught in stops without mixing books.

01Open the lesson hub and choose the section you need; the shared section bar keeps all five pages one tap apart.
02Project the Pupil’s or Student’s Book page and read the printed activity aloud, exactly as it appears in the book.
03Move to the Workbook for guided practice. The on-page reveals can be opened in class when you want the answer shown.
04Set the Lesson Test, then open the answer-key area on the same page to review the items together.

What the published answers can and cannot tell you

Set expectations before marking: some answers are printed in the book, some follow from it, and some do not exist.

Printed in the source

Answers labelled as explicit are readable directly in the supplied book pages. The Grade 3 Lesson 2 and Grade 4 Lesson 2 keys label each item this way or as inferred.

Direct reading

Follows from the source

Answers labelled as inferred follow from the printed grammar, sequence or meaning where the book prints no key. They are teaching judgements, not publisher answers.

Labelled inference

Not available at all

No listening or audio answer key exists anywhere in this repository because no official recording was supplied. Those items stay unscored and unanswered on purpose.
